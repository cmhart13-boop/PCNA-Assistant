# PCNA Assistant

Mobile-first Streamlit application for PCNA workflows. The interface is intentionally constrained to a phone-width canvas and follows the approved PCNA mobile layout: branded header, promotion hero, four primary workflow cards, and five-item bottom navigation.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Ownership

This repository and all application source are owned and controlled by the repository owner. Streamlit Community Cloud deploys directly from `app.py` on the `main` branch.
